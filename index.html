Comment créer ton bot backup :
1. Va sur @BotFather sur Telegram
2. Envoie /newbot
3. Pour le nom (le pseudo affiché) met le même nom que ton bot principal + Backup
4. Pour le @username met un vrai nom comme ton bot, ex: maboutique2_bot
5. Copie le token et colle-le au-dessus, puis « Vérifier »
